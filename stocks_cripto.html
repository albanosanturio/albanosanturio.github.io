Stocks and crypto feed — Dashboard and API

Status: WIP

A portfolio project built to demonstrate GCP competency — Cloud Run, BigQuery, Cloud Scheduler, IAM/auth patterns — rather than to produce investment insight. It pulls daily data for a handful of cryptocurrencies (BTC, ETH, SOL), stocks (SPY, QQQ, DIA), and macro indicators (Fed funds rate, 10-Year Treasury yield) from public APIs into BigQuery via scheduled, authenticated Cloud Run functions, with the goal of exposing it through a couple of FastAPI endpoints and a public Looker Studio dashboard.

All three data pipelines are live and automated; the API layer and dashboard are still in progress.

More details coming as the project develops.
